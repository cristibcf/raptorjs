# @raptorstack/test

**RaptorTest** — autonomous behavioral testing with a backend digital twin. It
discovers the application's behavior on its own, synthesizes a stateful fake
backend, and explores the state space:
**observe → infer → synthesize → explore → verify → replay**. Zero runtime
dependencies.

Part of [**RaptorStack**](https://github.com/cristibcf/raptorjs).

## Install

```bash
npm install -D @raptorstack/test
```

Includes VirtualClock, RaptorProbe, Semantic UI, Behavior Graph, RaptorTwin,
Explorer, Oracle, Chaos, Replay and Coverage.
